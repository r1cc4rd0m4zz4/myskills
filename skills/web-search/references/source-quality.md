# Source Quality Rubric

Rank information sources by epistemic quality and direct signal.

## Quality Levels

### Tier 5 — Primary / Practitioner (Highest Signal)
- Official documentation, RFCs, release notes
- Engineering blogs with reproducible benchmarks and code
- Source repositories and peer-reviewed arXiv papers

### Tier 4 — Specialist Media
- Tech journals with engineering focus (Ars Technica, The Verge, TechCrunch)
- Verified conference talks and transcripts

### Tier 3 — General Media
- News agencies (Reuters, AP, Bloomberg, BBC)
- Useful for event timelines; secondary for deep technical nuances

### Tier 2 — Commentary & Community
- Personal developer blogs, Reddit/HN discussions
- Useful for sentiment and edge-case gotchas; requires verification

### Tier 1 — Low Signal (Discard)
- SEO content farms, auto-generated scraper sites, unverified AI content

## Core Principles
1. **Convergence**: 2+ independent Tier-5 sources agreeing outweighs 10 aggregated low-tier mentions.
2. **Practitioner > Commentator**: Implementation truth comes from creators and maintainers.
3. **Negative Filtering**: Discard affiliate-laden or sponsored reviews before synthesis.
