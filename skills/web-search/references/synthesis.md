# Cross-Source Synthesis

Structure multi-source research into dense, verified briefings.

## Executive Synthesis Template

```markdown
## Executive Summary
Concise 2–3 sentence direct answer to the core question.

## Verified Findings
- **Point 1**: Direct finding with concrete metrics [Source Name](https://example.com/url).
- **Point 2**: Comparative trade-off or implementation detail [Source Name](https://example.com/url).

## Divergences & Nuances
- Disagreements or edge cases observed across independent sources.

## Discarded / Low-Signal Sources
- List any excluded outlier sources with reasoning.
```

## Guidelines
- **Data over Opinions**: Prefer quantitative metrics and code over claims.
- **Inline Citations**: Link source URLs directly in bullet points.
- **Explicit Uncertainty**: State missing information or ambiguous claims transparently.
