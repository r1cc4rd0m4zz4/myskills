## Contributing

Contributions are welcome! Please ensure:

1. **The Ladder (Anti-Bloat Engineering):** Native platform tools and standard libraries before dependencies. One line before fifty.
2. **Absolute Privacy:** Zero host leaks, zero internal usernames, or private paths. All examples, tests, and documentation must use generic placeholders.
3. **Deterministic Token Economy:** Prune metadata and HTML/JSON boilerplate (~80% token reduction target).
4. **Security by Default:** Zero unvalidated shell string interpolations, strict pre-resolution IP pinning for network requests.
5. **Quality & Tests:** All additions must pass `./scripts/verify.sh` with 100% success rate.
